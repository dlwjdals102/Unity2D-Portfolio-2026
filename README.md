**스프라이트와 사운드는 Phase 5 에서 들여온다.** GDD 아트 방침이 도형 프로토타입을

그 다음 단계다. 그림이 없으면 그림에 기대는 코드를 쓸 수 없어 설계상 이득이기도 했다.

**받는 즉시 위 표에 줄을 더한다.** 나중에 몰아 적으면 어느 그림이 어디서 왔는지 섞인다.
CC0 처럼 표기 의무가 없는 것도 적는다.
