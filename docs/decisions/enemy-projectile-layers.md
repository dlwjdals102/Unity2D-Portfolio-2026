# 적 투사체의 편은 레이어로 가른다

## 문제

`Projectile` 은 닿은 것이 `IDamageable` 이면 누구든 때린다. 플레이어만 쏘던 동안은 문제가 없었다.
플레이어 레이어와 투사체 레이어의 충돌을 매트릭스에서 꺼 두었기 때문이다.

원거리 적이 같은 스크립트로 쏘면 두 가지가 깨진다.

- **다른 적을 맞히고 죽인다.**
- **쏜 적 자신을 맞힌다.** 투사체는 쏜 적의 몸 한가운데서 태어나 처음부터 콜라이더가 겹쳐 있다.

그리고 적과 벽이 모두 `Default` 레이어에 있었다. 적만 따로 가를 수단이 없었다.

## 검토한 대안

### 안 A: 레이어와 충돌 매트릭스
`Enemy` 와 `EnemyProjectile` 레이어를 만들고, 적 프리팹을 `Enemy` 로 옮기고, 적 투사체 프리팹을 `EnemyProjectile` 에 둔다.

- 장점: **물리 단계에서 걸러 콜백 자체가 오지 않는다.**
- 장점: `Projectile` 과 `Health` 를 고치지 않는다. 투사체는 여전히 상대가 누구인지 모른다.
- 장점: 자기 몸에 맞는 문제도 같은 칸이 막는다.
- 장점: 플레이어와 적의 물리 충돌을 끊는 데 같은 레이어를 쓸 수 있다.
- 단점: 규칙이 코드가 아니라 프로젝트 설정에 있다. 코드만 읽어서는 보이지 않는다.
- 단점: 프리팹의 레이어를 잘못 두면 오류 없이 조용히 맞지 않는다.
- 단점: 레이어는 32칸뿐이고 Unity 가 앞의 여러 칸을 쓴다.

### 안 B: 코드로 편을 확인
`Launch` 에 쏜 편을 함께 넘기고, `OnTriggerEnter2D` 에서 맞은 쪽의 편과 같으면 무시한다.

- 장점: 규칙이 코드에 있어 읽으면 보인다. 레이어를 쓰지 않는다.
- 장점: 편이 게임 중에 바뀌는 기능(적을 아군으로 만드는 효과 같은 것)으로 넓히기 쉽다.
- 단점: 물리가 충돌을 다 계산하고 콜백까지 부른 뒤에 버린다.
- 단점: 맞은 쪽의 편을 알아야 해서 `IDamageable` 에 팀 개념이 들어가 인터페이스가 커진다.
- 단점: `Enemy` 레이어가 없어 플레이어와 적의 물리 충돌을 끊을 수단이 따로 필요하다.

### 안 C: 둘 다
레이어로 거르고 코드에서 한 번 더 본다. 지금 편은 둘뿐이라 두 번째 검사가 막을 일이 없다. 과설계로 버렸다.

## 선택과 이유

**A 를 골랐다.** Unity 가 이미 물리 필터링 수단을 갖고 있어 직접 만들 이유가 없었다.
B 의 장점인 '편이 바뀌는 기능' 은 GDD 에 없다. 없는 기능을 위해 인터페이스를 키우지 않았다.

[피해 명세](../specs/damage-death.md)가 `IDamageable` 로 '피해를 주는 쪽은 상대를 모른다' 를 만들어 두었고,
A 는 그것을 지킨다. B 는 투사체가 상대의 편을 알게 만들어 그 경계를 허문다.

끈 칸은 넷이다.

| 끈 짝 | 막는 것 |
|---|---|
| `EnemyProjectile` × `Enemy` | 다른 적과 쏜 적 자신을 맞히는 것 |
| `EnemyProjectile` × `Projectile` | 총알끼리 부딪혀 지워지는 것 |
| `EnemyProjectile` × `EnemyProjectile` | 같은 이유 |
| `Player` × `Enemy` | [플레이어와 적의 충돌 결정](player-enemy-collision-off.md)에 있다 |

## 결과

- **`Projectile` 과 `Health` 는 한 줄도 바뀌지 않았다.** 적 투사체는 프리팹과 데이터를 하나씩 더했을 뿐이다.
- 계단 5 는 코드 없이 확인만 했다. 적 총알이 근접 적을 지나가고, 벽에서 사라지고, 플레이어 총알과 서로 지나간다.
- **쏜 적의 몸 한가운데서 태어나도 자기 몸에 맞지 않는다.** 쏘는 위치를 몸 밖으로 밀어내는 코드가 필요 없었다.
- **설정에서 한 칸이 빠진 것을 파일을 읽어 잡았다.** 에디터에서 네 칸을 끄기로 했는데 `EnemyProjectile` × `Projectile` 이
  켜진 채였다. 적 투사체가 아직 없어 플레이로는 드러나지 않았고, `Physics2DSettings.asset` 의 매트릭스 값을 풀어 읽어 찾았다.

## 한계 / 남은 문제

- **편이 고정된 동안만 성립한다.** 게임 중에 적이 편을 바꾸는 기능이 오면 레이어를 오브젝트마다 바꿔 끼우거나
  B 로 가야 한다. 그때 이 문서가 뒤집힌다.
- **적을 `Default` 에서 옮기지 않으면 아무 일도 하지 않는다.** 벽과 같은 레이어에 있으면 끄는 순간 벽도 함께 통과한다.
  새 적 프리팹을 복제로 만들면 레이어가 딸려 오지만, 새로 만들면 `Default` 로 시작한다.
- **규칙이 코드 리뷰에 보이지 않는다.** 이번처럼 설정 파일을 읽어 확인하지 않으면 한 칸이 빠져도 모른다.
- 보스가 여러 종류의 투사체를 쏘더라도 편이 적 하나라면 레이어는 늘지 않는다.
