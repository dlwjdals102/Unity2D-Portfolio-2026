# 기획서 (GDD) — 1장 요약

> 규칙: 이 문서는 **A4 1장을 넘기지 않는다.**
> 넘어가면 3~4개월 안에 완성 못 하는 스코프라는 신호다.
> 기술 목표는 여기 적지 않는다 → [기능 후보 풀](feature-pool.md)

## 1. 한 줄 소개

**JM2D**: 아이템을 가방 어디에 놓느냐로 빌드가 갈리는, 20분짜리 2D 탑다운 액션 로그라이트.

- 시점: 탑다운 / 조작: 수동 조준 + 대시 회피
- 레퍼런스: 세피리아(가방·절차생성), 엔터 더 건전(조작), 뱀파이어 서바이버즈(물량)

## 2. 코어 루프

```
방 입장 → 적 웨이브 격파 → 아이템 획득 → 가방에 배치(빌드 결정) → 다음 방
```

**차별화 지점은 4번째 칸이다.** 아이템을 "먹는" 게 아니라 **"어디에 놓을지 고민하는"** 것이
이 게임의 정체성이다. 같은 아이템도 배치에 따라 성능이 달라진다.

## 3. 승리 / 패배 조건

- **승리**: 8번째 방의 보스 처치
- **패배**: HP 0 → 런 종료. 획득한 메타 재화만 유지하고 처음부터.
- **1회 플레이(런) 목표 시간**: 15~20분

## 4. 스코프 확정

| 항목 | 목표 수량 | 비고 |
|---|---|---|
| 플레이어 캐릭터 | 1 | 복수 캐릭터 없음 |
| 무기 | 3 | 근접 / 원거리 / 광역 |
| 적 종류 | 4 | 돌진 / 추적 근접 / 원거리 / 분열 |
| 보스 | 1 | 2페이즈 |
| 아이템 | 20 | **데이터만 추가하면 되도록 설계** |
| 가방 그리드 | 5 × 5 | 아이템은 1~4칸 차지 |
| 시너지 규칙 | 4종 | 인접 / 같은 행 / 같은 열 / 모서리 |
| 방 프리팹 | 8 | 절차적으로 배치·연결 |
| 방 1개당 웨이브 | 2~3 | 동시 등장 적 수를 높여 물량감 확보 |
| 메타 해금 | 5 | 무기·시작 아이템 해금만 |

## 5. 만들지 않을 것 (Non-Goals)

스코프 방어선. 만들고 싶어질 때마다 여기를 본다.

- [ ] **멀티플레이 / 협동**: 레퍼런스에 있어도 참는다. 시간 블랙홀.
- [ ] 스토리 · 컷신 · 대사 시스템
- [ ] 플레이어 캐릭터 복수
- [ ] 런 중간 저장 (메타 진행만 저장)
- [ ] 자체 아트 제작
- [ ] DOTS / ECS, 행동 트리 프레임워크 자작

## 6. 아트 방침

**도형 프로토타입을 기본값으로 개발한다.** 사각형과 원만으로 판독 가능하도록 설계한다.

- 색으로 역할 구분 (플레이어 / 적 / 투사체 / 벽 / 아이템)
- Phase 5에서 CC0 픽셀 에셋을 입힌다. **입히지 못해도 제출 가능한 상태를 항상 유지.**
- 이 방침은 렌더링과 로직 분리를 강제하므로 설계상 이득이기도 하다.
