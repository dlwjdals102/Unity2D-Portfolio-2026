# 기능 후보 풀

**장바구니가 아니라 후보 풀이다.**
얕은 기능 15개보다 깊은 기능 5개가 압도적으로 강하다.
GDD 스코프를 짤 때 여기서 골라 담는다.

각 기능은 아래 3개에 답할 수 있어야 "완성"으로 친다.

1. **수치가 있는가** — 프로파일러 캡처, 전후 비교
2. **대안을 검토했는가** — 왜 다른 방법을 버렸는가
3. **한계를 아는가** — 이 구조가 무너지는 조건은 무엇인가

3번을 스스로 말하는 지원자는 드물다. 그래서 기억에 남는다.

---

## S급 — 임팩트 대비 비용이 가장 좋다

### [ ] 1. 오브젝트 풀링 + 프로파일러 전후 수치
- 참고: 뱀파이어 서바이버즈
- 대량 스폰 테스트 씬을 별도로 만들어 둔다.
- **필수 산출물**: 적용 전/후 GC Alloc·프레임 타임 캡처 이미지
- 신입 포트폴리오에서 가장 확실한 한 방.

### [ ] 2. 데이터 주도 설계 + 커스텀 에디터 툴
- 적·아이템·무기를 ScriptableObject로 정의
- **여기서 멈추지 말 것**: 그걸 편집하는 에디터 창까지 직접 만든다.
- 툴 제작은 실무 비중이 큰데 해오는 신입이 거의 없다. 가성비 최고의 차별화.

### [ ] 3. 스탯 / 모디파이어 시스템
- 참고: 브로타토, 슬레이 더 스파이어
- 가산 → 승산 → 최종합 연산 순서, 스택 규칙, 지속시간 만료, 출처 추적
- 면접 대화가 가장 깊게 들어가는 주제. **EditMode 테스트 대상.**

### [ ] 4. 게임필 3종 (입력 버퍼 / 선입력 / 히트스톱)
- 참고: 데드 셀
- 구현 비용 최저, 체감 차이 최대.
- **사각형 데모에서도 그대로 작동하는 유일한 재미 요소.**

---

## A급 — 차별화 후보

### [ ] 5. 그리드 인벤토리 시너지
- 참고: 세피리아, 백팩 히어로, 백팩 배틀
- 배치 유효성 검증 + 인접 시너지 탐색
- 순수 로직이라 **EditMode 테스트 가능**. 그리드 UI는 사각형이 정상이라 아트 부재가 약점이 아닌 구간.

### [ ] 6. 절차적 생성 + 클리어 가능성 검증
- 참고: 스펠렁키 2 (솔루션 경로 보장)
- 방을 무작위로 잇는 건 흔하다. **BFS로 도달 가능성을 검증하고 실패 시 재생성**하는 부분이 차별화.
- **EditMode 테스트 대상** (연결성, 방 개수 보장)

### [ ] 7. 이벤트 기반 아키텍처
- UI가 `Update` 폴링을 하지 않는다는 것 자체가 설계 감각의 증거.

### [ ] 8. 세이브 / 로드 + 버전 마이그레이션
- 세이브 구조가 바뀌었을 때 구버전 파일을 읽어내는 처리
- 실무 감각을 보여주는 드문 항목.

## 함정 — 손대지 않는다

| 항목 | 이유 |
|---|---|
| **멀티플레이 네트워크** | 3~4개월 1인에게 시간 블랙홀. 미완성이면 감점. 세피리아·코어키퍼가 협동을 지원해도 참는다. |
| **DOTS / ECS** | Unity 6에서 가능하나 학습곡선이 프로젝트를 삼킨다. |
| **행동 트리 프레임워크 자작** | 적 4종에 BT는 과설계. CLAUDE.md 2번 위반. FSM으로 충분. |
| **커스텀 SRP / 셰이더 잔치** | 아트가 없는데 셰이더만 화려하면 앞뒤가 안 맞는다. |
